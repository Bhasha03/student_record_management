Student Record Management System

A deliberately small console project for introducing Python concepts. It is not a production system: its job is to make file handling and exception handling visible and understandable.

Learning objectives

  • Store each student as a dictionary and all students in a list.
  • Read and write a JSON text file using with open(...).
  • Use try / except for predictable file and input problems.
  • Validate menu choices, blank input, marks, duplicate roll numbers, and missing records.
  • Use a dictionary (FILE_PATHS) to look up the records and backup file names.

Run it

Open a terminal in this folder and run:

python student_record_manager.py

The first run has no data file. That is intentional: FileNotFoundError is handled and the program begins with an empty list. After adding a student, it creates student_records.json automatically. Option 5 writes a separate backup file.

Suggested classroom demonstration

  1. Run the program and add two students.
  2. View and search for a student.
  3. Try the same roll number again (duplicate check).
  4. Enter eighty or 105 as a mark (input validation and ValueError).
  5. Search or update an unknown roll number (common business edge case).
  6. Close and run again to show that data came from the file.
  7. Choose Backup and show that the second file was created.

Exception-handling discussion

Situation Handling in the project Why it is useful
Records file does not exist FileNotFoundError First run is normal, not a crash.
File has invalid JSON json.JSONDecodeError The user gets an explanation instead of a traceback.
Folder/file access is blocked PermissionError Saving or opening fails safely.
Other operating-system file issue OSError Covers situations such as a device/file problem.
A mark is not an integer ValueError The user can correct input and continue.
User presses Ctrl+C or input ends KeyboardInterrupt, EOFError The program finishes politely.

The project uses specific exceptions first. Avoid teaching a bare except: because it can hide programming mistakes.

Optional student extensions

  • Add a delete_record function with a confirmation prompt.
  • Add a grade (A, B, C, ...) from the mark.
  • Search by name using .lower().
  • Add attendance and calculate an average mark.
  • Ask students to intentionally corrupt student_records.json, observe the handled message, then repair the file.
