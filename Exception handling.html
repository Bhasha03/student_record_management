Classroom Test Sheet: Exceptions and Edge Cases

Run the program from this folder:

python student_record_manager.py

Use the starter data in student_records.json. Before changing that file for a file-error demo, make a copy named student_records_original.json in the same folder. Restore it after each file test by renaming it back to student_records.json.

Optional advanced exception demonstrations

These change code temporarily, so use them only after the core class demonstration. Undo the change immediately afterwards.

Exception Temporary code change Trigger Code location
PermissionError when reading At line 13, replace PROJECT_FOLDER / "student_records.json" with PROJECT_FOLDER and run. A folder cannot be opened as a normal file. Start program. student_record_manager.py:20-45
PermissionError when saving Make student_records.json read-only in File Explorer, then add a new student using STU007, Ishaan Verma, Python Basics, 82. Save attempted after entry. student_record_manager.py:48-60
TypeError while saving JSON Immediately after line 104, temporarily add record["extra"] = {"not", "json"}. Then add a student. A Python set cannot be saved as JSON. Save attempted after entry. student_record_manager.py:50-57

OSError is intentionally handled at lines 43-45 and 58-59, but it is not ideal for a live classroom demo because its exact cause varies by machine (for example, a file-system or hardware issue). The more predictable file exceptions above are better teaching examples.

Restore after file tests

Put the original valid JSON back into student_records.json, then start the program and choose menu option 2. Six starter records should display. The original data contains IDs STU001 through STU006; use STU007 for safe add-record examples.
